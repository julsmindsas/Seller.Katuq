FLUJO DE DATOS PASO A PASO
===========================

1. Usuario navegó a /agent-builder/wizard
   
2. WizardComponent.ngOnInit()
   - Inicializa 4 pasos
   - Llama loadToolCatalog()
   
3. loadToolCatalog()
   - Llama toolCatalogService.getToolCatalog()
   - GET /v1/agent-builder/catalog/tools
   
4. Backend retorna:
   {
     "success": true,
     "data": [
       { name: "getTotalSales", description: "...", department: "sales" },
       { name: "getProductStock", description: "...", department: "inventory" },
       ...
     ]
   }
   
5. ToolCatalogService.transformToCatalog()
   - Agrupa por departamento
   - Enriquece con iconos y categorías
   - Retorna ToolCatalog: { sales: [], logistics: [], inventory: [], general: [] }
   
6. WizardComponent asigna:
   this.toolCatalog = catalog
   
7. Step-Tools se inicializa con:
   - @Input() toolCatalog = ToolCatalog
   - @Input() agentConfig = { department: 'sales', selectedTools: [] }
   
8. StepToolsComponent.ngOnInit()
   - Llama loadAvailableTools()
   
9. loadAvailableTools()
   - const departmentTools = this.toolCatalog['sales']  // Tools de ventas
   - const generalTools = this.toolCatalog.general       // Tools generales
   - this.availableTools = [...departmentTools, ...generalTools]
   - Aplica filtros activos
   
10. Usuario ve grid con tools de su departamento
    
11. Usuario hace click en una herramienta:
    - toggleTool('getTotalSales')
    - Agrega a agentConfig.selectedTools
    - Emite agentConfigChange
    - Actualiza visualmente (check verde)
    
12. Usuario continúa a siguiente paso:
    - Valida que al menos una herramienta esté seleccionada
    - Emite next()
    
13. Step-Review muestra resumen:
    - Nombre, departamento, prompt, tools seleccionadas
    
14. Usuario hace click "Crear Agente":
    - WizardComponent.createAgent()
    - Crea CreateAgentRequest con selectedTools: ['getTotalSales', 'getProductStock']
    - agentService.createAgent(request)
    - POST /v1/agent-builder/create
    
15. Backend crea agente y retorna:
    {
      "success": true,
      "agent": { id: "...", agentName: "...", selectedTools: [...], ... },
      "message": "Agente creado"
    }
    
16. Redirecciona a /agent-builder/library
    - Muestra agente recién creado
