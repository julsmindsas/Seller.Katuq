¿Qué es el Dropshipping?

El dropshipping permite que tu empresa venda productos sin mantener inventario. Cuando un cliente hace un pedido, el producto se envía directamente desde el proveedor.

Solo un administrador puede cambiar esta configuración.

Aquí ves la que tiene tu empresa.

Al habilitar este módulo, los usuarios podrán configurar productos como dropshipping y gestionar órdenes con proveedores externos. Aplica para toda la empresa.
