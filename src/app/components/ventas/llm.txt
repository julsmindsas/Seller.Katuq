# CONTEXTO MÓDULO DE VENTAS - KATUQ SELLER

## DESCRIPCIÓN GENERAL
Este es el módulo de ventas de Katuq Seller, una plataforma Angular 14 para gestión de e-commerce. El módulo maneja creación de pedidos, gestión de clientes, punto de venta (POS), y todo el flujo de ventas.

## COMPONENTES PRINCIPALES DEL MÓDULO

### ESTRUCTURA DE CARPETAS
- **crear-ventas/** - Wizard de creación de pedidos
- **list/** - Listado y gestión de pedidos
- **clientes/** - Gestión de clientes
- **pos2/** - Punto de venta (POS)
- **venta-asistida/** - Proceso de venta asistida
- **carrito/** - Gestión del carrito de compras
- **checkout/** - Proceso de checkout
- **confirm/** - Confirmación de pedidos

### COMPONENTES POS (PUNTO DE VENTA)
- **product-category/** - Navegación por categorías
- **customer-section/** - Selección de clientes
- **cart-summary/** - Resumen del carrito
- **payment-selector/** - Selección de método de pago
- **cash-payment/, card-payment/, ewallet-payment/** - Procesadores de pago
- **cash-closing/** - Cierre de caja

### SERVICIOS PRINCIPALES
- **VentasService** - Gestión de ventas y pedidos
- **CartSingletonService** - Estado global del carrito
- **PosCheckoutService** - Operaciones específicas del POS
- **PedidosUtilService** - Utilidades y cálculos de pedidos

## FUNCIONALIDADES CLAVE

### MULTI-CANAL DE VENTAS
- Creación tradicional de pedidos por wizard
- Interfaz de punto de venta para retail
- Venta asistida para ventas guiadas
- Carga masiva de ventas

### INTEGRACIÓN DE PAGOS
- Múltiples métodos de pago (efectivo, tarjeta, billetera)
- Integración con gateway Wompi
- Registro manual de pagos
- Cierre de caja diario

### CARACTERÍSTICAS ESPECÍFICAS COLOMBIA
- Estructura de direcciones colombianas
- Facturación electrónica
- Métodos de pago locales
- Cálculo de impuestos según regulación colombiana

### FILTROS Y BÚSQUEDA AVANZADA
- Filtros multi-criterio para pedidos
- Búsqueda en tiempo real
- Exportación (Excel, PDF)
- Rangos de fechas personalizados

## PUNTOS DE INTEGRACIÓN
- **Sistema de Inventarios** - Disponibilidad en tiempo real
- **Módulo de Producción** - Seguimiento del ciclo de vida
- **Módulo de Despachos** - Envío y cumplimiento
- **Dashboard de Analytics** - Reportes y KPIs de ventas
- **Gateways de Pago** - Procesamiento de pagos electrónicos

## TECNOLOGÍAS UTILIZADAS
- Angular 14 con TypeScript
- PrimeNG para componentes UI
- RxJS para programación reactiva
- Firebase para backend y hosting
- SCSS para estilos
