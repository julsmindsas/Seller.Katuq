Cómo se agenda

Cada cita tiene hora de inicio y dura lo que dure el servicio. Cada persona atiende una cita a la vez. Ideal para peluquería, consultorio o taller.

El cliente elige una franja (por ejemplo 8:00 - 10:00) y caben varias citas por franja. Ideal para visitas técnicas o instalaciones a domicilio.
