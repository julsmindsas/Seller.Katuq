# 🎤 Guión de Demo - Agente de Voz Gemini para Katuq Seller

**Fecha**: 2025-09-30
**Duración estimada**: 5-7 minutos
**Objetivo**: Demostrar el poder del agente de voz con IA para crear ventas completas en Katuq

---

## 🎯 Preparación (ANTES de la demo)

### ✅ Checklist Pre-Demo

1. **Abrir la aplicación** en `http://localhost:4200`
2. **Iniciar sesión** con credenciales de demo
3. **Verificar que tienes**:
   - ✅ Al menos 1 bodega configurada
   - ✅ Al menos 5 productos en inventario
   - ✅ Conexión a internet estable
4. **Abrir el agente de voz**:
   - Click en el botón flotante (esquina inferior derecha)
   - Seleccionar "Live Audio"
5. **Probar micrófono**: Decir "Hola" y verificar que responde

### 🎨 Ventana Recomendada
- **Pantalla completa** del navegador
- **DevTools cerradas** (F12)
- **Modo presentación** activado

### 2️⃣ DEMO RÁPIDA - Venta Completa en 1 Comando (2 minutos)

Busca una camiseta, créala para un cliente llamado Juan Pérez."

4. ✅ Crea el cliente "Juan Pérez" con datos automáticos
5. ✅ Configura facturación para Juan Pérez
6. ✅ Configura envío a Bogotá
7. ✅ Procesa la venta con pago en efectivo
8. ✅ **CREA EL PEDIDO REAL EN LA BASE DE DATOS**

**[Mientras sucede, narrar]**:

## 🎭 Consejos de Presentación

### ✅ Hacer
- **Hablar claro y pausado** al micrófono
- **Resaltar las visualizaciones 3D** mientras aparecen
- **Celebrar con entusiasmo** cuando se completen las ventas
- **Mostrar el número de pedido** generado como prueba real
- **Si algo falla**, usar el comando de demo rápida como backup

### ❌ Evitar
- No hablar muy rápido (la IA necesita tiempo para procesar)
- No interrumpir a la IA mientras habla
- No usar comandos ambiguos (ser específico)
- No preocuparse por errores menores (la IA los maneja)

## 📊 Datos Técnicos (Para Preguntas)

## 🎬 Plan B (Si algo sale mal)

### Problema: La IA no responde
**Solución**: Refresh de página + reiniciar sesión

### Problema: No encuentra productos
**Solución**: Usar "cualquier producto" en lugar de nombre específico

### Problema: Error en creación de cliente
**Solución**: Usar comando de demo rápida que autocompleta datos

### Problema: Audio no funciona
**Solución**: Mostrar el modo chat tradicional como alternativa
