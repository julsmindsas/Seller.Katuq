# 📱 Guía Rápida: Demo desde Celular

**Optimizado para**: iPhone, Android, tablets
**Duración**: 3-5 minutos
**Objetivo**: Mostrar el agente de voz funcionando perfectamente en móvil

---

## 🚀 Preparación Rápida (2 minutos antes)

### 1. Conexión
```
✅ Conectar celular a WiFi estable
✅ Abrir navegador (Chrome/Safari recomendados)
✅ Ir a: http://[TU-IP-LOCAL]:4200
   Ejemplo: http://192.168.1.10:4200
✅ Iniciar sesión
```

### 2. Verificación Rápida
```
1. Toca el botón flotante (esquina inferior derecha)
2. Selecciona "Live Audio"
3. Permite acceso al micrófono cuando lo pida
4. Di "Hola" y espera respuesta
5. Si responde → ¡Listo para demo! ✅
```

## 📱 Tips Específicos para Móvil

### ✅ Hacer

1. **Sostén el celular cerca** (~20cm de tu boca)
2. **Habla claro y pausado** (no rápido)
3. **Espera** que la IA termine antes de hablar de nuevo
4. **Observa** las visualizaciones 3D mientras responde
5. **Gira el celular** a landscape para mejor vista (opcional)

### ❌ Evitar

1. No cubras el micrófono con los dedos
2. No hables mientras la IA está respondiendo
3. No uses en lugares muy ruidosos
4. No cierres el navegador mientras graba
5. No actives modo avión

## 🎯 Comandos de Emergencia (Si algo falla)

### Si no escucha
```
1. Verifica permiso de micrófono (ícono en barra de navegador)
2. Recarga la página (F5)
3. Permite micrófono nuevamente
```

### Si se cuelga
```
1. Di "Dame el estado actual"
2. Espera respuesta
3. Continúa desde donde quedó
```

### Si falla todo
```
1. Cierra el navegador
2. Abre de nuevo
3. Inicia sesión
4. Usa comando mágico: "Realiza una demostración rápida"
```

1. **Proyecta la pantalla** del celular si es posible (casting/cable)
2. **Activa el modo No Molestar** (sin notificaciones interrumpiendo)
3. **Carga completa** (100% batería)
4. **Brillo al máximo** (para que la audiencia vea bien)
5. **Prueba 2-3 veces antes** en el mismo lugar (por el ruido ambiente)

### Para troubleshooting rápido
- Ten otro celular/laptop como backup
- Conoce de memoria el comando mágico
- Ten abierto el docs/GUION_DEMO_GEMINI_VOICE.md en otro dispositivo
