# Documentacion Katuq

## Estructura

- `arquitectura/`: modelos, interfaces, endpoints y arquitectura general.
- `componentes/`: documentacion por componentes del frontend.
- `features/`: guias por funcionalidad de producto.
- `integraciones/`: integraciones externas y proveedores.
- `migraciones/`: notas de cambios y migraciones.
- `ui-ux/`: guias de experiencia, responsive y mejoras visuales.
- `historico/`: Markdown que antes estaban sueltos en la raiz del repositorio.
