# Política de Privacidad - MotiApp LUXURY

## Descripción

Esta página contiene la Política de Privacidad completa para MotiApp - LUXURY, la aplicación premium de frases motivadoras.

## Acceso a la Página

### Desarrollo Local
Para acceder a la página de política de privacidad en desarrollo local:

1. Inicia el servidor de desarrollo:
```bash
npm start
```

2. Navega a la URL:
```
http://localhost:4200/privacy-policy
```

### Producción (Firebase Hosting)

Para desplegar la página en Firebase Hosting:

1. Construye la aplicación:
```bash
npm run build-privacy
```

2. Despliega en Firebase:
```bash
npm run deploy-privacy
```

3. Accede a la página en:
```
https://julsmind-katuq.firebaseapp.com/privacy-policy
```

## Mantenimiento

### Actualización de Contenido
Para actualizar el contenido de la política de privacidad:

1. Edita el archivo: `src/app/components/privacy-policy/privacy-policy.component.html`
2. Actualiza la fecha en el componente TypeScript
3. Construye y despliega nuevamente

### Actualización de Estilos
Para modificar los estilos:

1. Edita el archivo: `src/app/components/privacy-policy/privacy-policy.component.scss`
2. Los cambios se reflejarán automáticamente en desarrollo
3. Para producción, ejecuta el build y deploy
